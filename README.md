# Haji Tila Catering & Tent Service — Website

A premium static website for a catering, deg, tent and event-arrangement service in Peshawar. Light ivory/sand pages with deep forest green and gold, food-focused, with a quick-quote card, a menu builder and WhatsApp enquiries.
Visitors explore services and send enquiries by **WhatsApp**, **phone** or **directions** — there is no cart, checkout, pricing or login.

**Stack:** Next.js 15 (App Router, static export) · TypeScript · Tailwind CSS v4 · GSAP + ScrollTrigger · Lenis · Lucide icons.
Fonts (Cormorant Garamond + Manrope) are bundled locally.

---

## 1. Installation

Requires **Node.js 20+**.

```bash
npm install
```

## 2. Development

```bash
npm run dev
```
Open http://localhost:3000

## 3–4. Production build & static export

```bash
npm run build
```
`next.config.ts` uses `output: "export"`, so the complete website is written to the **`out/`** folder as plain HTML/CSS/JS/images. No server, database or API is needed. Preview it locally with `npm start` (runs `npx serve out`).

## 5. WhatsApp number

Edit **`data/business.ts`** — the single source of truth for all contact details:

```ts
whatsapp: "923001234567",   // international format, digits only, no "+" or spaces
```

Every WhatsApp button, the floating button, the mobile bar, service-specific messages and the quotation form use this value.
While the placeholder `"92XXXXXXXXXX"` is in place, every WhatsApp button (and the hero quick-quote card) takes visitors to the on-page enquiry form instead, so nothing ever links to a broken number. Call and Directions buttons similarly scroll to the Contact section until a phone number and Maps link are set.

Message wording lives in `lib/contact.ts` (`DEFAULT_WHATSAPP_MESSAGE`, `serviceMessage`, `buildEnquiryMessage`).

## 6. Phone number

```ts
phone: "0300-1234567",
```
Local numbers starting with `0` are converted to `tel:+92…` automatically. Leave it `""` to disable Call buttons.

## 7. Google Maps

Open the business in Google Maps → **Share** → **Copy link**, then:

```ts
googleMapsUrl: "https://maps.app.goo.gl/....",
```
"Get Directions" buttons stay disabled until this is set (no URL is guessed). No paid Maps API is used. Optionally add `googleReviewUrl` to show a "Review Us on Google" button.

## 8. Logo

Place your logo at `public/logo.svg`, then edit `components/ui/Logo.tsx` (instructions are in the file comment). Favicons are in `public/icons/`.

## 9. Gallery & photos

**Gallery:** add real event photos to `public/images/gallery/` and list them in `data/gallery.ts` (an example entry is in the file). Until at least one photo is listed, the Gallery section shows a "Request Photos on WhatsApp" panel instead of placeholder pictures — customers are never shown images that aren't your own work.

**Before / After slider:** add `public/images/before-after/before.webp` and `after.webp` (same venue, empty and prepared), then set `beforeAfter.enabled: true` in `data/content.ts`.

**Backgrounds:** the hero, About, occasion cards and final banner use abstract atmospheric images (soft drapes, chandelier glow and bokeh — not photos of specific events). They are generated by `scripts/atmosphere.py` and can be replaced with your own photos using the same file names:

| Area | Files |
|---|---|
| Hero | `public/images/hero/hero-bg.webp` (desktop), `hero-bg-mobile.webp` (portrait) |
| About | `public/images/about/about.webp` |
| Occasion cards | `public/images/events/*.webp` |
| Final banner | `public/images/hero/final-cta.webp` |
| Social share image | `public/images/og-image.jpg` (1200 × 630) |

When using real photos, keep the darker left side of the hero image free of busy detail so the headline stays readable.

## 10. Services

Edit `data/services.ts` (title, description, image, and the name used in the WhatsApp message). The enquiry form options (`eventTypeOptions`, `requiredServiceOptions`) are in the same file.

## 11. Events, menu & FAQ

- Occasions: `data/events.ts`.
- **Build Your Menu:** dishes and groups (English + Urdu names) are in `data/menu.ts`. Dishes a visitor ticks are added to the WhatsApp quote message under "Menu Preferences". No prices are shown.
- **FAQ:** questions and answers are in `data/faqs.ts` (also published as FAQ structured data for Google). Keep answers to confirmed facts — e.g. add booking notice or deg sizes once confirmed.

## 12. Testimonials

Add **genuine** reviews only, with permission, to `data/testimonials.ts`. While empty, the site shows "Client testimonials will appear here."

Optional statistics (years, events served …) are in `data/content.ts` → `stats`, hidden by `showStats: false`. Turn them on only with verified figures.

## 13. Address

`data/business.ts` → `address`, `addressLines`, `plusCode`.

## 14. SEO

- Site URL: `data/business.ts` → `siteUrl` (used for canonical URL, sitemap, Open Graph).
- Title, description, keywords: `lib/seo.ts`.
- LocalBusiness structured data is generated in `lib/seo.ts` from verified details only; telephone, map and social links are added automatically once configured. No ratings, prices or opening hours are published.
- `robots.txt` and `sitemap.xml` are generated at build time (`app/robots.ts`, `app/sitemap.ts`).

All other text is in `data/content.ts`.

## 15. Deploy to cPanel (shared hosting / Namecheap)

1. Run `npm run build`.
2. Open the **`out/`** folder and select **everything inside it** (not the folder itself). Zip it.
3. In cPanel → **File Manager** → `public_html` (or your domain's folder) → **Upload** the zip.
4. Right-click the zip → **Extract**. Make sure `index.html`, `_next/`, `images/` sit directly inside `public_html`.
5. Delete the zip. Visit your domain.

The export uses folders with `index.html` (`trailingSlash: true`) and a `404.html`, so no `.htaccess` rules are required. Optionally add `ErrorDocument 404 /404.html` to `.htaccess`.

## 16. Deploy to Netlify

- **Drag & drop:** run `npm run build`, then drag the `out/` folder onto https://app.netlify.com/drop.
- **From Git:** build command `npm run build`, publish directory `out`.

## 17. Deploy to Vercel

Import the Git repository at https://vercel.com/new. Vercel detects Next.js and the static export automatically. (Cloudflare Pages: build command `npm run build`, output directory `out`.)

## 18. Domain connection

- **cPanel:** point the domain's nameservers to your host (or add it as an Addon Domain), and upload into that domain's folder.
- **Netlify / Vercel:** Project → Domains → add your domain, then create the DNS records they show (usually an `A` record for the root and a `CNAME` for `www`) at your registrar.
- Update `siteUrl` in `data/business.ts` to the final domain and rebuild.

## 19. Image optimisation

- Use **WebP** (or AVIF) at roughly 1600–1920 px wide for full-width images and 1200 px for cards; aim for under 300 KB each.
- Tools: https://squoosh.app or `cwebp -q 80 input.jpg -o output.webp`.
- Below-the-fold images already use `loading="lazy"`; the hero sky layer is preloaded.

Regenerating the background images (optional): `pip install numpy pillow`, then `python3 scripts/atmosphere.py`.

## Motion & accessibility

- Animations are slow and subtle; `prefers-reduced-motion` disables smooth scrolling, parallax, particles, the custom cursor, pinned scroll sections and reveals, and shows the finished line drawing.
- The custom cursor appears only on mouse/trackpad devices.
- No WebGL is used: the hero is an atmospheric image with gentle parallax and a 2D-canvas particle layer, and "Imagine Your Event" is an SVG line drawing — it works on every device.
- Hero text is animated with CSS, so content is visible even if JavaScript fails.
- The menu and gallery lightbox trap focus and close with Escape; the lightbox supports arrow keys and swipe; the before/after slider works with the keyboard.
